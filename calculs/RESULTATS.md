# Résultats reproductibles

## 1. Valeur brute

La formule V1 produit :

[
2.2335763974987408	imes10^{-22}
]

Ce résultat arithmétique est reproductible avec `reproduce.py`.

## 2. Conversion conditionnelle

**Condition :** supposer, sans l'avoir encore démontré, que la sortie est en grammes.

Alors :

[
m = 2.2335763974987408	imes10^{-25};mathrm{kg}
]

En utilisant les définitions SI exactes de (e) et (c), on obtient :

[
1;mathrm{GeV}/c^2
=
1.7826619216278977	imes10^{-27};mathrm{kg}
]

Donc :

[
m_{mathrm{Brutus}}
approx
125.294447051355;mathrm{GeV}/c^2
]

## 3. Comparaisons externes

Deux références PDG ne doivent pas être confondues :

- Table récapitulative PDG 2025 : **125.20 ± 0.11 GeV**.
- Revue électrofaible PDG 2025, moyenne LHC indiquée : **125.08 ± 0.07(stat) ± 0.05(syst) GeV**.

Écarts numériques du candidat conditionnel :

| Référence | Écart absolu | Écart relatif |
|---|---:|---:|
| 125.20 GeV | +0.094447051 GeV | +0.07544 % |
| 125.08 GeV | +0.214447051 GeV | +0.17145 % |

## 4. Interprétation

Ces écarts justifient une **étude**, pas une conclusion causale.

La proximité dépend de la référence utilisée. Le dépôt doit donc conserver toutes les références pertinentes et éviter le choix après coup de la valeur la plus favorable.
