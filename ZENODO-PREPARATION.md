## Pourquoi le dépôt est encore privé

Zenodo indique que son application GitHub n'a **pas accès aux dépôts privés**. La publication par intégration GitHub exige donc un dépôt public.

Une alternative est un dépôt Zenodo manuel avec fichiers restreints; dans ce cas les métadonnées restent publiques.
