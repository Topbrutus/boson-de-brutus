# Protocole de falsification — Brutus V1

Le but n'est pas de protéger la formule. Le but est de lui donner une chance réelle d'échouer.

## Verrous

1. V1 reste inchangée.
2. Toutes les variantes futures portent V2, V3, etc.
3. Aucun nouveau facteur n'est ajouté après observation du résultat ciblé.
4. Toutes les tentatives pertinentes doivent être enregistrées, y compris les échecs.
5. Les références expérimentales sont choisies avant la comparaison finale.

## Tests prioritaires

### T1 — Analyse dimensionnelle
Établir une chaîne d'unités qui mène réellement à une masse, ou conclure que l'unité « g » n'est pas dérivable.

### T2 — Sensibilité
Faire varier chaque paramètre autour de sa valeur et mesurer si la proximité avec le Higgs est robuste ou extrêmement ajustée.

### T3 — Null models
Comparer la performance de la relation à de nombreuses formules de complexité similaire générées sans viser le Higgs.

### T4 — Historique des essais
Reconstituer combien de transformations ont été essayées avant le gel afin d'estimer le risque de sélection a posteriori.

### T5 — Prédiction hors échantillon
Définir, **avant de regarder la réponse**, une nouvelle quantité calculable par la même règle ou une extension théoriquement motivée.

### T6 — Réplication indépendante
Fournir le code et demander à un tiers de reproduire les résultats sans intervention de Topbrutus.

## Condition d'abandon scientifique

La relation doit rester documentée comme curiosité numérique si :
- aucune unité cohérente n'est dérivable;
- aucun mécanisme n'est proposé;
- les null models montrent que des rapprochements similaires sont courants;
- aucun test hors échantillon n'est réussi.

Un échec documenté reste un résultat utile.
